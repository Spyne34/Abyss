# Abyss

Produit par 5 graphistes et 5 programmeurs de troisième année sur un temps de production d'environ 12 semaines ce jeu contemplatif est réalisé à l'aide du moteur Unreal Engine 4.

Durant ce projet j'ai travaillé sur l'Intelligence Artificielle en réalisant le comportement du petit poisson qui suit le joueur, j'ai également pu apprendr à utiliser le moteur de son Fmod afin d'intégrer tous les sons et les musiques du jeux et j'ai créé des outils pour rendre l'intégration de ces sons et de ces musiques plus facile mais aussi plus harmonieuse et organique.
